# 🏹 Archero 2 — Калькулятор злиття екіпірування (Merge Calculator)

🌐 **Онлайн-версія для клану:** [https://isakawar.github.io/Archero-2/](https://isakawar.github.io/Archero-2/)

Інтерактивний веб-калькулятор злиття та синтезу спорядження для гри **Archero 2**.

---

## 🎯 Можливості калькулятора

1. **Вибір цільової рідкості предмета:**
   * Сірий (Common)
   * Зелений (Great)
   * Синій (Rare)
   * Фіолетовий (Epic, Epic +1, Epic +2)
   * Золото (Legendary, Legendary +1, Legendary +2, Legendary +3)
   * Червоний (Mythic)

2. **Підрахунок сумарних еквівалентів:**
   * Всього потрібно базових (Common) сірих предметів.
   * Фіолетових (Epic) еквівалент.
   * Золотих (Legendary) еквівалент *(1 Золотий = 216 Сірих)*.

3. **Покроковий ланцюжок синтезу:**
   * Детальна схема проміжних крафтів із зазначенням конкретних предметів (той самий лук/предмет) та корму (будь-який предмет того ж рівня).

4. **Повна таблиця витрат ресурсів з нуля:**
   * Точний розподіл на специфічні предмети та корм для кожного рівня.
