# 🏹 Archero 2 Upgrade Calculator (Веб-калькулятор прокачки)

Сучасний інтерактивний веб-калькулятор та компаньйон для гри **Archero 2**, створений для планування прокачки спорядження та рун, підрахунку дефіциту ресурсів і визначення пріоритетів фарму.

---

## 🚀 Швидкий запуск

### 1. Запуск у режимі розробки:
```bash
npm run dev
```
Відкрийте в браузері: `http://localhost:5173`

### 2. Збірка для продакшну:
```bash
npm run build
```
Зібрані статичні файли створюються у папці `dist/`.

### 3. Запуск модульних тестів (чистий калькулятор):
```bash
npm test
```

---

## 🎯 Реалізований функціонал

1. **Обладнання (Equipment)**:
   - Всі слоти: *Weapon, Armor, Ring, Bracelet, Necklace, Spellbook*.
   - Каталог відомих предметів гри (Brightspear, Demon Blade, Death Scythe, Golden Chestplate, Lion Ring тощо) з пошуком та фільтрами.
   - Запобігання дублікатам: додавання того ж предмета автоматично об'єднує та збільшує кількість копій.
   - Вибір поточної та цільової рідкості (*Common, Great, Rare, Epic, Perfect Epic, Gold +0...+5, Legendary +0...+3, Mythic*).
   - Лічильник копій `[-] 3 [+]`.
   - Кнопка **[Шлях прокачки]** (Upgrade Tree) з деталізацією кожного проміжного кроку.

2. **Руни (Runes)**:
   - Каталог рун (*Руна Мужності, Руна Сили, Руна Зцілення, Руна Удачі, Руна Опірності*).
   - Вибір поточного та цільового рівня (Lv. 1 - Lv. 20).
   - Підрахунок фрагментів, золота та пилу рун.

3. **Ресурси (Resources & Inventory)**:
   - Введення золота, сувоїв, пилу рун зі швидкими кнопками додавання (+50k, +100k, +1M).
   - Автоматичне локальне збереження (`localStorage`). Будь-яка зміна ресурсів негайно перераховує всі цілі.

4. **Масовий план ("MY UPGRADE PLAN")**:
   - Об'єднання всіх цілей спорядження та рун в єдиний план.
   - Підсумок **TOTAL**: скільки всього потрібно золота, копій, фрагментів та сувоїв.

5. **"Що мені зараз фармити?" (FARMING PRIORITY)**:
   - Автоматично перетворює сумарний дефіцит у чіткий пріоритетний список:
     1. Копії конкретних предметів (Brightspear copies: Need X).
     2. Фрагменти рун (Rune fragments: Need X).
     3. Сувої (Scrolls).
     4. Золото (Gold).
     5. Спеціальні матеріали.

6. **Кнопка [⚙️ Дані прокачки]**:
   - Дозволяє в будь-який момент переглянути та змінити вартості прокачки без редагування коду.
   - Підтримує редагування через візуальну таблицю або прямий RAW JSON з можливістю копіювання, збереження та скидання до стандартних mock-значень.

## 🏗️ Архітектура проєкту

- **`src/engine/calculator.js`**: Чисті функції розрахунків, повністю ізольовані від UI:
  - `calculateUpgradeCost(from, to, type, gameData)`
  - `calculateUpgradeChain(from, to, type, gameData)`
  - `calculateMissingResources(required, owned)`
  - `calculateProgress(required, owned)`
  - `calculateTotalPlan(equipment, runes, resources, gameData)`
  - `getFarmingPriority(totalPlan)`
- **`src/engine/calculator.test.js`**: Набір модульних тестів (перевірка багатокрокових ланцюжків, відсутності від'ємних чисел, відсутності дублювання, edge cases).
- **`src/data/defaultGameData.js`**: Конфігурація гри з чітко позначеними **MOCK DATA**, яку легко модифікувати.
- **`src/components/`**: Модульні компоненти інтерфейсу у стилі modern mobile game companion.
